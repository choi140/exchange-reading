# 디자인 방향

## 지금 디자인 (17단계)

사용자가 준 참고 이미지 두 장(굵은 제목과 기울어진 책등, 왼쪽 사이드바와 흰 카드 격자)의 느낌으로 frontend-design 스킬을 써서 다시 만들었다. 아래 "처음 디자인"은 기록으로 남겨 둔다.

- **핵심 장면:** 처음 화면의 입자감 있는 책등 세 권. 그림이 아니라 교환독서·교환일기·독서 달력으로 가는 버튼이다. 제목 "밑줄"에는 파란 펜 밑줄을 그어 앱의 이름을 그대로 보여 준다.
- **색:** 종이 `#F7F5EF`, 면 `#FFFFFF`, 잉크 `#191919`, 연필 `#66635C`, 줄 `#E3DFD5`, 강조 `#BF5A14`. 책등·표지는 주황 `#E5803A`, 남색 `#2E3F6B`, 겨자 `#EDC061`.
- **글꼴:** 제목 Black Han Sans, 앱의 말 Gothic A1. 책 본문·일기·인용은 Gowun Batang, 손글씨는 Nanum Pen Script를 그대로 쓴다.
- **글자 크기:** 18단계에서 한 단계씩 줄였다. 리더 기본 16px, 앱의 안내 13~14px, 소제목 21px, 화면 제목 32px.
- **그림자:** 흐린 그림자 대신 책등·표지에만 검은 면 그림자를 준다. 나머지는 흰 카드와 여백으로 나눈다.
- **색의 규칙:** "펜 색 = 사람"은 글과 밑줄에서 그대로 지킨다. 책등·표지 색은 책을 뜻하고, 같은 책은 언제나 같은 색이다. 읽는 화면에는 쓰지 않는다.

## 처음 디자인 (Todo 1-5)

frontend-design 스킬의 절차(계획 → 브리프와 대조해 수정 → 구현 → 스크린샷으로 자기 비평)를 따라 정했다.

## 주제에서 출발하기

- **무엇을 만드나:** 낯선 사람과 한 권의 책·한 권의 일기장을 돌려 쓰는 익명 웹앱.
- **누가 쓰나:** 책과 기록을 좋아하는 20~30대. 주로 휴대폰으로, 밤에 천천히 읽고 쓴다.
- **화면의 주된 일:** 본문을 편하게 읽게 하고, 그 옆에 남긴 "다른 사람의 손글씨"를 발견하게 한다.
- **주제의 재료:** 돌려 읽은 책의 여백, 색이 다른 볼펜, 공책 줄, 도서관 대출 카드, 밑줄.

## 핵심 아이디어: 펜 색이 곧 사람이다

이 앱에서 사람은 이름도 얼굴도 없이 **펜 색**으로만 구분된다(검정·파랑·초록·주황). 그래서 색은 장식이 아니라 정보다. 화면의 바탕은 조용한 종이와 잉크로 두고, 색은 오직 "누가 썼는가"를 나타낼 때만 쓴다.

과감함은 한 곳에만 쓴다: **메모와 밑줄은 손글씨체(Nanum Pen Script)로, 그 사람의 펜 색으로** 쓰인다. 본문은 인쇄된 명조, 메모는 볼펜 손글씨 — 실물 교환독서의 감각을 그대로 옮긴 대비다. 로고 "낯선 밑줄" 아래에도 파란 펜으로 그은 듯한 손그림 밑줄 하나만 둔다.

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 종이 (paper) | `#EEF0EA` | 바탕. 갱지처럼 살짝 회녹빛이 도는 차가운 종이 |
| 지면 (page) | `#FAFBF7` | 본문·쓰기 칸처럼 "글이 놓이는 면" |
| 잉크 (ink) | `#232838` | 본문 글자. 순흑이 아니라 청흑색 만년필 잉크 |
| 연필 (pencil) | `#6B7064` | 보조 글자, 설명, 비활성 |
| 여백선 (margin) | `#D9A3A0` | 공책 왼쪽 여백의 붉은 세로줄. 리더의 메모 여백 경계 |
| 검정 펜 | `#232838` | 혼자 모드의 나 |

## 글꼴

| 글꼴 | 역할 |
|---|---|
| Gowun Batang (고운바탕) | 책 본문, 제목. 읽는 글 |
| Gowun Dodum (고운돋움) | 버튼, 안내, 목록 같은 앱의 말 |
| Nanum Pen Script (나눔손글씨 펜) | 사람이 손으로 쓴 것: 메모, 로고 밑줄 옆 낙서, 오늘의 질문 |

세 글꼴 모두 `@fontsource` 패키지로 앱에 직접 넣어 외부 요청 없이 불러온다.

- 본문: 18px / 줄간격 1.95 / 한 줄 최대 약 34자(한글) — 휴대폰에서 눈이 편한 길이.
- 크기 단계: 14 · 16 · 18 · 22 · 30 · 44px.
- 대문자 라벨, 가운데점으로 이은 메타 정보, 화살표 붙은 버튼은 쓰지 않는다.

## 배치

모바일 한 줄 배치가 기본이고, 큰 화면에서도 폭 640px 안에 왼쪽 정렬로 둔다(책 한 쪽의 폭).

```
홈 /                         리더 /room/[id]               일기장 /diary/[id]
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│ 낯선 밑줄          │        │ ← 홈   [● 검정 펜] │        │ ← 홈   혼자 쓰는 일기│
│ ~~~~~~ (파란 밑줄) │        │ 운수 좋은 날        │        │ ┌ 오늘의 질문 ────┐│
│ 한 줄 소개          │        │ 현진건              │        │ │ 손글씨 질문      ││
│                  │        │┃                  │        │ └──────────────┘│
│ 책장               │        │┃ 문단 1 ......  ② │        │ ═══ 공책 줄 쓰기칸 ═│
│ ─ 운수 좋은 날      │        │┃ 문단 2 ......    │        │ 0/1000   [일기 남기기]│
│   현진건 · 1924    │        │┃ 문단 3 ......  ① │        │                  │
│   [혼자 읽기][함께]  │        │  ↑ 붉은 여백선, 오른쪽│        │ 지난 일기          │
│ 내 책 (비었을 때 안내)│        │    여백에 메모 개수   │        │ ─ 11월 1일 ...     │
│ 내 일기장 [새 일기장] │        └──────────────────┘        └──────────────────┘
└──────────────────┘
```

- 구분은 그림자 카드 대신 **선**으로 한다: 목록은 가는 가로줄, 리더는 붉은 여백선, 쓰기 칸은 공책 줄.
- 둥근 모서리는 버튼(손가락이 누르는 것)에만, 면에는 거의 쓰지 않는다.

## 원칙

1. 색은 사람을 뜻할 때만 쓴다.
2. 인쇄된 글(명조)과 손으로 쓴 글(펜 손글씨)을 섞지 않는다.
3. 움직임은 사용자가 무언가를 열고 닫을 때만 (선택창, 메모 열기). 저절로 움직이는 효과는 없다.
4. 빈 화면은 다음 행동을 알려준다 ("책장에서 한 권 골라 혼자 읽기를 눌러 보세요").

## 브리프와 대조해서 바꾼 것

- 처음 떠올린 안은 **따뜻한 크림색 종이 + 명조 + 테라코타 포인트**였다. 책 앱이면 누구나 떠올릴 기본값이라, 바탕을 회녹빛 갱지로 바꾸고 포인트 색을 따로 두지 않았다. 대신 네 가지 펜 색이 포인트 역할을 나눠 맡는다.
- 책 목록을 그림자 있는 카드 격자로 그리려다, 도서관 대출 카드처럼 **가는 줄로 나뉜 목록**으로 바꿨다. 카드 격자는 어떤 앱에나 나오는 모양이고, 책 세 권에는 목록이 더 읽기 쉽다.
- 섹션마다 영문 대문자 라벨(BOOKS, MY DIARY)을 붙이려던 것을 뺐다. 한글 제목 하나로 충분하다.
