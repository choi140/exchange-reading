**커밋 규칙 (PRD #12).** 할 일 1~3개가 끝날 때마다 커밋하고 push한다. 메시지는 할 일 번호와 내용을 함께 적는다. 예: `[1-7] 홈 화면: 책 목록, 내 책, 내 일기장 영역 추가`.

**변경 기록 규칙 (PRD #12).** 할 일을 추가·삭제·수정하면 맨 아래 'Todo 변경 내역'에 바로 적는다. README 3번 항목의 재료가 된다.

- [x] 4-5 블라인드: 내 메모도 unlock도 없는 문단은 "숨겨진 메모 N개"만 표시 (PRD #4.1)

- [x] 4-9 push → 자동 배포 확인 (PRD #8)

**확인 방법** (일반 창·시크릿 창·다른 브라우저 = 낯선 사람 3명)
- 세 창에서 같은 책을 "함께 읽기"하면 같은 방에 들어가고, 펜 색이 서로 다르다.
- A가 메모를 남긴 문단이 B에게는 "숨겨진 메모 1개"로 보이고, B가 메모를 쓰거나 "그냥 보기"를 누르면 열린다.
- B가 A의 메모에 답글을 달면 A 창을 새로고침했을 때 보인다.
- 네 번째 사용자(새 시크릿 창)는 새 방에 들어간다.

- 마지막 문단 아래 편지를 남기면 같은 방 사람에게 보인다.

- 넓은 화면에서 참여 코드 방을 페이지 모드로 열어도 1쪽에서 다음 쪽으로 넘어간다.
- 교환일기에서 A가 나가면 B의 화면에 "짝이 교환일기를 떠났어요"가 뜨고, 홈 내 일기장에 "끝남"이 보인다.

**확인 방법**

- 스크롤 모드에서 본문 왼쪽에 색 띠가 없다.
- 보기 설정에서 글자 크기에 24를 넣으면 바로 24px로 바뀌고, 다시 들어와도 그대로다.
- PC에서 페이지 모드를 켜면 두 쪽이 나란히 보이고, 창을 좁히면 한 쪽으로 돌아온다.

## 14단계. 내 취향대로 보기 (v11)

**목표:** 읽는 화면과 책장을 내가 고른 모양으로 쓴다.

- [x] 14-1 보기 설정에서 한 화면에 볼 쪽 수 고르기: 자동(900px 이상 두 쪽) · 한 쪽 · 두 쪽(700px 이상, 휴대폰은 한 쪽) (13-4 고침)
- [x] 14-2 글자 크기를 바꾸면 책 머리(제목, 저자, 함께 읽는 사람, 안내 글)도 같은 비율로 커지게 (13-3 고침)
- [x] 14-3 책장 배치 고르기: 목록 · 2열 · 3열 · 표지 크게. 고른 배치는 브라우저에 기억
- [x] 14-4 책 표지: 이미지가 없는 책은 제목과 저자로 만든 글자 표지, 이미지는 `public/covers/`에 넣고 `src/data/covers.ts`에 이으면 바로 표시
- [ ] 14-5 **[직접]** 배포 주소에서 확인, 표지 이미지가 있으면 전달

**확인 방법**
- 페이지 모드의 보기 설정에서 한 쪽을 고르면 PC에서도 한 쪽으로 보이고, 두 쪽을 고르면 두 쪽으로 보인다.
- 글자 크기를 27px로 올리면 책 제목과 안내 글도 함께 커진다.
- 교환독서 책장 위에서 2열·3열·표지 크게를 고르면 배치가 바뀌고, 새로고침해도 그대로다. 휴대폰에서 가로로 넘치지 않는다.

## 15단계. 책장 다시 다듬기 (v12)

- 휴대폰에서 4열로 봐도 버튼 글자가 잘리지 않고 가로로 넘치지 않는다.

## 16단계. 듣기 (v13)

**목표:** 눈을 쉬면서도 책을 이어 갈 수 있게, 기기의 음성으로 책을 읽어 준다.

- [x] 16-1 듣기(TTS): 리더 위 "듣기" 버튼으로 지금 읽는 문단부터 소리 내어 읽기. 멈추기·이어 듣기, 앞·다음 문단, 속도 0.8~1.5배, 한국어 목소리가 여럿이면 고르기, 읽는 문단 표시와 따라가기. 브라우저 음성(Web Speech API)을 써서 비용·서버 없음. 들은 문단도 독서 달력에 쌓임
- [x] 16-2 **[직접]** 배포 주소에서 PC·휴대폰으로 소리가 나는지 확인

**확인 방법**
- "듣기"를 누르면 지금 문단부터 소리가 나고 그 문단이 옅게 칠해지며, 다음 문단으로 넘어가면 화면도 따라간다.
- 멈추기 후 이어 듣기를 누르면 멈춘 문장부터 다시 읽는다. 속도를 바꾸면 바로 적용되고, 닫으면 소리가 멈춘다.
- 다른 화면으로 나가면 소리가 멈춘다.
- 한국어 음성이 없는 기기에서는 "들을 수 없어요" 안내가 뜬다.

- [x] 17-2 처음 화면: 큰 제목, 참여 코드 입력칸, 눌러서 이동하는 책등 세 권
- [x] 17-3 사이드바를 아이콘이 있는 흰 패널로, 책장·내 책·내 일기장을 흰 카드로, 표지를 색 표지로
- [x] 17-4 밤 모드와 휴대폰 화면 맞추기, 기념 카드 색 맞추기
- [ ] 17-5 **[직접]** 배포 주소에서 PC·휴대폰·밤 모드로 확인

**확인 방법**

- 책장의 3열·4열에서 같은 책은 언제나 같은 색 표지다.

- 밤 모드에서 글자가 잘 보이고, 휴대폰에서 가로로 넘치지 않는다.
