# 구현 Todo

> 원본: [Claude Doc · Todo 탭](https://claude.ai/artifact/CzzFGXDqp23qeduMBbtov1)

6단계, 할 일 73개(v3). 화면을 먼저 만들고 기능을 나중에 붙인다. **[직접]**이 붙은 할 일은 계정 만들기·키 입력·버튼 누르기처럼 직접 해야 하는 일이고, 나머지는 Claude가 한다. 괄호 안 번호는 PRD의 장 번호다.

**커밋 규칙 (PRD #12).** 할 일 1~3개가 끝날 때마다 커밋하고 push한다. 메시지는 할 일 번호와 내용을 함께 적는다. 예: `[1-7] 홈 화면: 책 목록, 내 책, 내 일기장 영역 추가`.

**변경 기록 규칙 (PRD #12).** 할 일을 추가·삭제·수정하면 맨 아래 'Todo 변경 내역'에 바로 적는다. README 3번 항목의 재료가 된다.

**확인 방법**

- 같은 책을 다시 "혼자 읽기"로 열면 새 방이 아니라 기존 방이 열린다.
- 혼자 일기를 2편 쓰면 목록에 2편이 보이고, 홈에 내 책·내 일기장이 나타난다.
- 시크릿 창(다른 익명 사용자)에서는 이 메모와 일기가 보이지 않는다.

## 4단계. 함께 읽기

**목표:** 낯선 사람 최대 3명이 같은 책 방에서 펜 색으로 구분된 메모를 주고받는다.

- [x] 4-1 DB 함수 join_room(book_id) 작성: 이미 들어간 방 → 3명 미만인 방 → 새 방 순서로 찾기 (PRD #4.1, #9)
- [x] 4-2 join_room에서 남은 펜 색(파랑·초록·주황)과 별명("파란 펜") 배정 (PRD #4.1)
- [x] 4-3 "함께 읽기" 버튼을 누르면 배정된 방으로 이동 (PRD #4.1)
- [x] 4-4 함께 방의 메모를 작성자 펜 색·별명으로 표시하고, 리더 상단에 내 펜 색 표시 (PRD #4.1)
- [x] 4-5 블라인드: 내 메모도 unlock도 없는 문단은 "숨겨진 메모 N개"만 표시 (PRD #4.1)
- [x] 4-6 "그냥 보기" 버튼을 누르면 unlocks에 저장하고 메모 열기 (PRD #4.1, #9)
- [x] 4-7 메모 아래 답글 쓰기 (parent_id, 한 단계만) (PRD #4.1)
- [x] 4-8 혼자 방에서는 블라인드·답글이 나타나지 않게 mode로 분기 (PRD #4.1, #9)
- [x] 4-9 push → 자동 배포 확인 (PRD #8)

**확인 방법** (일반 창·시크릿 창·다른 브라우저 = 낯선 사람 3명)
- 세 창에서 같은 책을 "함께 읽기"하면 같은 방에 들어가고, 펜 색이 서로 다르다.
- A가 메모를 남긴 문단이 B에게는 "숨겨진 메모 1개"로 보이고, B가 메모를 쓰거나 "그냥 보기"를 누르면 열린다.
- B가 A의 메모에 답글을 달면 A 창을 새로고침했을 때 보인다.
- 네 번째 사용자(새 시크릿 창)는 새 방에 들어간다.
