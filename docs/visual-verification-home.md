# 처음 화면 다듬기 기록 (19-4, image-to-code 스킬)

기존 디자인이 밋밋해서 책을 주제로 한 디자인 레퍼런스를 찾았고, 새 처음 화면을 레퍼런스와 나란히 보며 다듬었다.

- **화면 찍기:** 스킬의 `render_screenshot.py`는 Playwright가 필요해서, PC의 Edge 헤드리스 모드로 1440×922 화면을 찍었다.
- **나란히 보기:** 스킬의 `scripts/visual_compare.py`와 눈으로 레퍼런스와 화면을 비교했다.

## 다듬은 곳

| 부분 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 책등 간격 | 기울기가 커서 겹치고 검은 그림자가 가려짐 | 기울기를 13·7·2도에서 8·4·1도로 줄이고 위치를 조정 |
| 동그란 화살표 버튼 | 입력 전에 회색으로 흐림 | 입력 전 불투명도를 40%에서 70%로 |

## 앱에 맞게 남긴 곳

| 부분 | 이유 |
|---|---|
| 한글 제목과 파란 펜 밑줄 | 앱 이름 "낯선 밑줄"을 그대로 보여 준다 |
| 왼쪽 사이드바 | 앱의 메뉴가 많아 위쪽 가로 메뉴보다 오가기 쉽다 |
| 눌러서 이동하는 책등 | 장식이 아니라 교환독서·교환일기·독서 달력으로 가는 버튼이다 |
